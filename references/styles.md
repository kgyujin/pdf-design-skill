# 스타일·색조 선택 가이드

## 스타일

| 스타일 | 모양 | 어울리는 문서 | 피할 때 |
|---|---|---|---|
| `swiss` | 연한 표지 + 제목 위 굵은 먹색 룰, 제목 아래 굵은 룰, KPI 위 먹색 룰 | 운영·분석 보고서, 기술 문서, 기본값 | 감성적인 브랜딩 문서 |
| `editorial` | 가운데 정렬 표지, 가는 이중 룰, 큰 리드 문단, 세로 구분선 KPI, 테두리 없는 카드 | 에세이, 회고, 인터뷰, 연구 요약 | 수치·표가 많은 문서 |
| `bold` | 어두운 전면 표지, 큰 제목, 어두운 표 헤더, 굵은 먹색 KPI 룰, 어두운 콜아웃 | 경영 보고, 피치, 발표 자료 | 흑백 인쇄(잉크 소모가 큼) |
| `minimal` | 흰 표지(장식 없음), 룰 없는 제목, 넓은 여백, 가벼운 굵기 | 제안서, 포트폴리오, 이력서 | 정보 밀도가 높은 문서 |
| `tech` | 어두운 표지, `[1]` 번호, 점선, 코드풍 기호 | 개발 문서, 아키텍처·장애 리포트 | 비개발 독자 대상 문서 |
| `academic` | 흰 표지, 얇은 가로 룰, 얇은 표 룰, 장식 없음, 강조색 최소 | 논문·세미나 발표, 연구 보고서 (발표 자료 모드 기본값) | 인상이 강해야 하는 마케팅 문서 |
| `soft` | 연한 포인트 면 표지, 둥근 모서리, 연한 배경 카드 | 교육 자료, 온보딩, 서비스 소개 | 격식이 필요한 공문 |
| `classic` | 격자 표, 이중 테두리 표지, 가운데 정렬 제목, 넓은 행간 | 공문, 학위논문 요약, 법무·금융 보고서 | 캐주얼한 소개 자료 |
| `split` | 좌우 면 분할 표지, 굵은 포인트 바, 포인트색 표 머리 | 제안서, IR, 마케팅·서비스 소개 | 흑백 인쇄 |

## 색조

| 색조 | 인상 | 용도 |
|---|---|---|
| `indigo` | 중성·차분한 파랑 | IT·스타트업 |
| `navy` | 신뢰·보수적 | 공공, 금융, 기업 보고 |
| `terracotta` | 따뜻한 종이 톤 | 에세이, 인문, 브랜딩 |
| `forest` | 차분함·안정 | ESG, 헬스케어, 교육 |
| `plum` | 개성·크리에이티브 | 디자인, 마케팅, 포트폴리오 |
| `mono` | 흑백(포인트도 검정) | 흑백 인쇄, 이력서, 공문 |
| `graphite` | 흑백 중심 + 차분한 청회색 포인트 | **기본값**. 대부분의 문서, 연구 발표 |
| `crimson` | 강렬·경고 | 리스크 보고, 브랜드 캠페인 |
| `teal` | 깨끗함·데이터 | 헬스케어, 핀테크, 데이터 리포트 |
| `sand` | 따뜻한 종이 + 올리브 | 인문, 여행, 라이프스타일 |

## 추천 조합
- 운영·분석 보고서: `swiss` + `graphite`/`navy`
- 경영진 보고·피치: `bold` + `navy`
- 회고·에세이: `editorial` + `terracotta`
- 이력서·포트폴리오: `minimal` + `mono`/`plum`, 원페이저 템플릿
- 개발 문서: `tech` + `forest`/`indigo`, 밀도 `compact`
- 논문·세미나 발표(흑백 미니멀): `academic` + `graphite` (`talk` 템플릿 기본값)
- 강의·교육 자료: `soft` + `teal`/`indigo`
- 공문·금융 보고서: `classic` + `navy`/`mono`
- 제안서·IR: `split` + `navy`/`crimson`

## 세부 조정 기준
- 브랜드 색이 정해져 있으면 가장 가까운 색조를 고르고 `--accent`로 포인트색만 맞춘다. 배경·본문 색은 색조의 중성색을 쓴다.
- 쪽수를 줄여야 하면 `--density compact`를 먼저 쓰고, 그래도 넘치면 내용을 줄인다.
- 바탕체·명조체는 사용자가 요청했을 때만 쓴다. 제목만이면 `--font serif`, 본문까지면 `--font serif-all`(고운바탕). editorial·classic과 잘 어울리지만, 이 스타일을 골랐다는 이유만으로 바탕체를 켜지 않는다.
- 바탕체로 만든 문서를 화면 발표에 쓸 때는 본문까지 바꾸는 `serif-all`보다 제목만 바꾸는 `serif`를 권한다(멀리서 읽기 쉬움).
