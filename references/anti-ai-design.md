# 목적 없는 반복을 줄이는 디자인 검토

모양 하나만으로 AI가 만든 디자인이라고 판정하지 않는다. 비교 카드, 큰 숫자, 넓은 색면은 내용을 더 잘 전달할 수 있다. 중요한 것은 역할과 반복 정도다. 사용자 지시가 기본 취향보다 우선한다.

## 반드시 고칠 문제

- 잘림, 겹침, 읽기 어려운 대비, 너무 작은 차트 내부 글씨
- 뜻 없는 수치·관계, 자료에 없는 사실, 출처 왜곡
- 축·범례·분모가 빠져 해석이 바뀌는 그림
- 효과 때문에 데이터나 핵심 문구가 묻히는 화면

## 반복을 검토할 표현

| 표현 | 유지할 수 있는 목적 | 재검토할 상황 |
|---|---|---|
| 큰 숫자와 색면 | 주요 결과를 먼저 읽게 함 | 모든 숫자가 같은 강도로 강조됨 |
| 비교 카드 | 같은 속성의 대상 둘 이상 비교 | 정보와 관계없는 같은 카드가 반복됨 |
| 번호·칩·세로선 | 순서, 단계, 분류 구분 | 모든 제목에 장식처럼 붙음 |
| 영문 대문자 라벨 | 섹션·표준 약어 식별 | 과반 페이지에서 제목을 중복 설명 |
| 하단 요약 | 판단이나 다음 행동 연결 | 모든 장을 상투적인 주의 문구로 마감 |
| 같은 레이아웃 | 같은 기준의 연속 비교 | 서로 다른 역할의 페이지도 같은 배치 |
| 강조색 | 데이터 그룹, 중요한 차이 | 라벨·불릿·숫자가 모두 경쟁 |

동일 배치가 세 장 이상 이어지면 내용상 필요한지 확인한다. 이 숫자는 자동 탈락 기준이 아니다. 대문자나 `01` 번호, 카드 수만으로 실패 처리하지 않는다.

## 선택할 수 있는 표현

넓은 색면, 비교 카드, 관계 도형, 번호, 제한적인 그림자·그라데이션은 주제와 사용자 취향에 따라 선택한다. 투사·인쇄에서 대비가 유지되고, 시각적 그룹화나 시선 유도에 도움이 되는지 확인한다. 의미 없는 빈 공간 채우기나 과도한 효과는 피한다. 색은 토큰으로 관리해 테마 전환을 유지한다.

## 발표 자료에서 지향하는 것

- 밝은 표지에 큰 제목과 선택적 주제 이미지를 배치한다. 표지에 KPI·결론·목차·설명 문단을 기본으로 넣지 않는다.
- 표, 큰 단일 차트, 사례 쌍, 조건 비교, 결론 표를 내용 역할에 맞게 선택한다.
- 핵심 숫자를 크게 쓸 수 있지만 같은 숫자를 차트·상자·하단에 세 번 반복하지 않는다.
- 원본 이미지 사용 조건을 지키며 차트 내부 글씨를 실제 화면에서 읽는다.
- 색을 빼도 읽는 순서가 남고, 색을 더했을 때 비교가 더 분명해야 한다.

## 검수 기록

자동 경고는 점검 후보다. 각 경고를 수정하거나 유지 이유와 수동 확인 결과를 기록한다. 오류는 모두 수정한다. 전체 축소판으로 흐름을 확인하고 모든 페이지의 개별 이미지를 열어 판독한다. A/B는 동일 내용의 표지·핵심 증거·결론 세 페이지에서 구조를 비교하며, 팔레트만 바꾼 안으로 대신하지 않는다.
