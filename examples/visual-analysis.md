# 전체 시각 디자인 예제

`visual-analysis.json`은 가상의 물류 분석을 소재로 한 7쪽 예제다. 내용의 정답이나 분석 방법을 가르치는 템플릿이 아니라, 전체 페이지의 시각 체계를 확인하는 제작 원본이다. 모든 수치는 가상이다.

## 디자인에서 볼 부분

- 표지: 넓은 여백과 큰 타이포, 선택적인 주제 이미지. 본문과 색·서체를 공유하되 정보 밀도를 낮춘다.
- 2쪽: 문자·숫자·도넛의 크기 대비. 오른쪽 면은 한 시각자료와 그 해설을 묶는다.
- 3쪽: 같은 축과 같은 강조 규칙을 사용하는 두 그래프. 모든 막대를 진하게 칠하지 않는다.
- 4쪽: 큰 분포 차트와 하나의 강조 영역. 데이터와 주석의 면적 차이를 만든다.
- 5쪽: 두 축의 비교를 보여 주는 색 셀, 정확한 수치, 정렬된 보조 설명. 참고 3조의 교차표 페이지처럼 정보가 같은 자리에 놓인다.
- 6쪽: 본문 절차를 도형·선·텍스트로 편집할 수 있는 도식. 본문의 비교색과 선 규칙을 공유한다.
- 7쪽: 전체 폭 표로 마무리. 셀 간격과 행 구분선으로 읽는 순서를 정리한다.

실제 자료를 만들 때 7개 형식을 전부 채울 필요는 없다. 자료에 필요한 시각 형식을 고르고 제목 위치·외곽 여백·서체·색의 의미를 일관되게 유지한다. 참고 자료가 제공되면 이 예제의 색·레이아웃보다 사용자의 참고 디자인을 우선한다.

## 만들기와 편집

```bash
python3 SKILL_DIR/scripts/pdfdesign.py pptx SKILL_DIR/examples/visual-analysis.json ./out/example.pptx
```

사용자는 생성된 PPTX를 PowerPoint에서 직접 편집한다. 2~4쪽의 차트는 ‘데이터 편집’, 7쪽 표는 셀 클릭, 나머지 도형·문구는 개별 선택으로 수정한다. 5쪽 heatmap은 색 도형과 텍스트로 이루어져 있으므로 값과 셀 색을 각각 바꾼다. 내장 차트처럼 자동 색 재계산을 하지 않는다. 표지는 본문 분석과 분리하고 제목·발표 정보만 편집한다.

수정한 PPTX에서 PDF를 내보낸다. 수동 수정 뒤 원래 JSON을 실행하면 편집 내용이 되돌아가므로 PPTX를 정본으로 사용한다. 폰트는 Pretendard이며 PPTX에 내장하지 않는다. PDF 내보내기 전 폰트 설치 또는 원하는 폰트로의 전체 교체 후 줄바꿈을 확인한다.

스킬의 네이티브 출력은 기본 차트 4종만 지원한다. 복잡한 시각자료는 사용할 수 있는 전용 도구로 만들되, 이미지와 데이터 편집형 차트를 구분해 제공한다. 전체 사용법·한계는 `references/editable-presentations.md`를 따른다.
