# 편집 가능한 발표 자료 디자인 요청

아래 항목을 채워 사용한다. 지정하지 않은 항목은 제공 자료와 사용 환경에 맞게 판단한다.

```text
pdf-design 스킬로 발표 자료를 디자인해줘.
원본 자료: {{파일}}
디자인 참고 PDF: {{파일 / 없음}}
목표 페이지 수: {{페이지 수 / 원본 유지}}
화면 비율: {{16:9 / 기타}}
주제: {{발표 주제}}
색상: {{자동 선택 / 지정 팔레트 / 기존 색 유지}}
저장 위치: {{경로}}
결과물: PowerPoint에서 편집할 PPTX와 같은 원본에서 출력한 PDF
```

## 적용 지침

1. 디자인만 요청한 경우 글의 주장·문장·숫자·순서를 임의로 바꾸지 않는다. 내용이 길면 배치를 조정하고 필요한 경우 페이지 분리를 검토한다.
2. 참고 PDF 전체를 렌더링해 서체·위계·정렬축·여백·밀도·색의 의미·시각자료 통합 방식을 분석한다. 개별 도형이나 그래프만 흉내 내지 않는다.
3. 표지는 표지 역할만 맡긴다. 제목·부제·팀/발표자·날짜·주제 이미지 외에 KPI·결론·목차·설명 본문을 기본으로 넣지 않는다.
4. 팔레트는 명시 설정 > 저장한 선호 > 주제 기반 선별 조합 > neutral 순으로 선택한다. 색 유지 요청이 있으면 자동 선택으로 덮어쓰지 않는다.
5. 특별히 요청하지 않은 ‘출처’ 라벨·출처 푸터·참고자료 페이지를 화면에 추가하지 않는다. 자산 경로와 원본 페이지는 별도 제작 메타데이터로 남긴다.
6. 페이지마다 같은 상자를 반복하지 않는다. 제목·여백·서체는 일관되게 유지하고 자산에 맞춰 차트 중심, 표 중심, 대상 이미지, 공통 축 비교의 화면 비율을 달리한다. 형식 종류를 채우기 위해 불필요한 그림을 만들지 않는다.
7. 텍스트·표·도식·지원 차트는 PowerPoint 네이티브 개체로 만든다. 차트에는 편집할 데이터를 포함하고 이미지로 남는 부분의 편집 한계를 안내한다.
8. 제공 PNG 사용 조건을 지킨다. 그래프를 재제작할 경우 실제 수치와 축·단위·범례를 유지한다. 관측 그래프를 이미지 생성 모델로 만들지 않는다.
9. 전체 축소판과 모든 개별 페이지를 검수한다. 잘림·정렬·폰트·차트 내부 글자·색 의미·페이지 간 밀도 변화를 확인한다. 자동 오류 0건을 디자인 완성도의 근거로 대신하지 않는다.
10. 실제 PPTX 편집과 같은 원본의 PDF 출력 경로를 확인하고 사용 앱, 미검증 범위, PDF/PPTX 링크를 간단히 보고한다.
